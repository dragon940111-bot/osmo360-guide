# Osmo 360 II · 스냅픽 A1 가이드북

DJI Osmo 360 II와 코닥 스냅픽 A1(필름 카메라) 사용법을 사진과 그림으로 정리한 개인용 가이드북입니다.

- 첫 화면은 Osmo 360 II 가이드북이고, 위쪽 노란 **「스냅픽 A1 →」** 버튼으로 스냅픽 A1 가이드북으로 넘어갑니다. 주소 끝에 `#snapic`을 붙이면 스냅픽 쪽이 바로 열립니다.
- 두 가이드북이 `index.html` 한 파일 안에 들어 있어서, 오갈 때 빈 화면이 생기지 않습니다. 휴대폰 뒤로가기를 누르면 이전 가이드북으로 돌아갑니다.
- 휴대폰에서 이 사이트를 열고 **홈 화면에 추가**하면 앱처럼 열립니다. 한 번 열어 두면 그다음부터는 인터넷 없이도 열립니다.
- 사진 161장, 그림, 글꼴이 모두 `index.html` 안에 들어 있습니다.
- 사진 출처: DJI 공식 Osmo 360 II 튜토리얼 영상 캡처, 코닥 스냅픽 A1 빠른 시작 가이드(공식 PDF), RETO 공식 제품 사진, 유튜브 영상 대표 장면 썸네일. 필름 결과 예시 사진은 시뮬레이션이며 실제 필름 결과가 아닙니다.
