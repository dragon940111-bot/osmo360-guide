# 카메라 가이드북 (Osmo 360 II · 스냅픽 A1 · GZ-MG760)

DJI Osmo 360 II, 코닥 스냅픽 A1(필름 카메라), JVC 캠코더 GZ-MG760(일본 내수판) 사용법을 사진과 그림으로 정리한 개인용 가이드북입니다.

- 첫 화면은 Osmo 360 II 가이드북이에요. 위쪽 색 버튼(노랑 = 스냅픽, 주황 = 캠코더, 하늘색 = 오즈모)으로 어느 가이드북에서든 다른 두 권으로 바로 넘어가요. 주소 끝에 `#snapic`나 `#gz`를 붙이면 그 가이드북이 바로 열려요.
- 세 가이드북이 `index.html` 한 파일 안에 들어 있어서 오갈 때 빈 화면이 생기지 않아요. 휴대폰 뒤로가기를 누르면 이전 가이드북으로 돌아가요.
- 휴대폰에서 이 사이트를 열고 **홈 화면에 추가**하면 앱처럼 열려요. 한 번 열어 두면 다음부터는 인터넷 없이도 열리고, 인터넷이 될 때 열면 최신 버전으로 바뀌어요.
- 사진 242장, 그림, 글꼴이 모두 `index.html` 안에 들어 있어요.
